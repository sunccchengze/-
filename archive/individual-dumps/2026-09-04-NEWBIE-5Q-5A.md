## 第 1 问：大二大三想出国交换 / 暑研，和暑期支教撞车怎么办？

> 💭 新生真实担忧：不是"我没时间"，而是"我怕这是一条单行道"——怕报了项目部就等于签了"卖身契"，怕 GPA 掉了想补、想出国想刷经历，但社团不放人。

### 孙承泽答
- **所有暑期活动从来都不是强制性的**，肯定可以不去
- 玉树是**面向全校招志愿者**的
- 总体而言，**没有任何强制性的规定**，不用过于担心
- 你可以**大一在社团担任干事**，到了**大三之后的暑假或者其他暑假**，自己找什么时间自己有空就去参加

## 第 2 问：部门内部真的没有 KPI 和形式主义吗？学长学姐私下吐槽过什么？

> 💭 新生真实担忧：怕"非志愿的杂事"成为主要消耗；怕情感消耗没人管；想知道真实失败 / 崩溃 / 累，而不是只有高光。

### 孙承泽答
- **非志愿的杂活其实挺少的**——每周**最多两个小时时间**，肯定不占公共课余时间
- 来社团主要是为了**快乐**，不会让你们那么累
- **没有任何的 KPI 和形式主义**
- **部门例会确定就是两周一次**
- 微信公众号推文会要求做，但**都轮流做的**——一个部门那么多人，可能就轮到一次或两次，不会很忙
- **不可能出现工时不够被点名**，或者"不好意思拒绝任务"
- 你要忙的话，**拒绝就行**
- **要以自身成长和学业为主**
- 社团就是一个让你们**放松交朋友**的地方，千万别有多大负担
- （萤火部）确实面临患病儿童——你可以**选择其他部门**参加

## 第 3 问：面试到底筛什么样的人？内向 / 没"学生领导力" 是不是没戏？

> 💭 新生真实担忧：怕面试被筛；怕内部小团体；怕"机会按熟面孔分配"。

### 孙承泽答
- 面试**是会刷人**的
- 但只要有**一颗真挚的公益的心**，就不会被刷
- 另外看个人能力——**看你的表现力是否适合部门的工作**
- 来社团是**可以选学技能的**，不一定得吃老底
- 技能不会也没关系，**慢慢就都会了**
- **大家其实都差不多，都是慢慢成长起来的**
- 社团内部**没有小团体**，也没有什么"熟人圈"这种说法
- **崇实书院的占比并不高**——这是一个**全校性的社团**
  - 例：我是彭康书院的，还有其他励志书院、钱学森书院、文治书院等等都有
- **大家一开始都不认识，然后越玩越熟，最后都认识了**

## 第 4 问：这个经历对保研 / 出国 / 找工作，真的有用吗？

> 💭 新生真实担忧：不是来做慈善，是来给自己攒未来的。想知道"英仔"两个字在申请季的含金量。

### 孙承泽答
- **志愿工时和暑期实践学分**有学校要求标准，**咱们这边可以轻松完成**
- **加综测里的德育分**
- **评优评先中有优势**
- 第四个问题我也答不上来——**我觉得社团就是结识志同道合的朋友，一起做喜欢做的事情的地方**

## 第 5 问：能和一个孩子/老人建立真实关系吗？病房孩子没挺过去怎么办？

> 💭 新生真实担忧：怕"表演善良"；怕"来了又走"是又一个外地老师；怕公益变成"我给希望、我离开"的残忍。

### 孙承泽答
- **可以啊，完全没问题**
- 后面可能会有**频繁的微信交流**
- **不要当做表演**——你自己拿真心对待，**他们就会用真心回报你**
- 病房孩子们的问题——**我也不会答**
- 所以很需要你的**真心和长期坚持**

## 5 答核心信息

### 真话 vs 宣传话术
| 宣传话术 | 真话 |
|----------|------|
| 玉树是英仔的灵魂 | 玉树是面向全校的，**不强制**，可大三大四再去 |
| 部门例会两周一次 | ✅ 真实——确定就是两周一次 |
| 制度清爽不搞形式主义 | ✅ 真实——非志愿杂活每周最多 2 小时 |
| 推文 / 视频需要人手 | ✅ 真实——但轮流做，每人每学期 1-2 次 |
| 面试真诚就好 | ✅ + "表现力适合部门工作" 也会看 |
| 跨书院 8 书院 | ✅ 真实——崇实占比并不高 |
| 简历上写"英仔" | **部分真**——加德育分 + 评优评先有用；申请季直接变现不承诺 |

### 风险预警（给下一届宣传部）
- **问题 1（卖身契）**——新生最常有的担忧。**答得坚定**："不强制、可大三大四去"。
- **问题 2（KPI / 形式主义）**——**这是 FAQ 里从没正面回答过的**。新一届应在破冰会时**主动说"每周最多 2 小时、推文轮流、不用不好意思拒绝"**。
- **问题 3（小团体）**——**真实**——崇实占比并不高，但**仲英占比偏高**。新一届应主动说"我们来自 N 个书院"具体数字。
- **问题 4（功利）**——**孙承泽自己也答不上来**——这恰好是真实。新一届可以坦诚说"社团不是为你简历服务的"。
- **问题 5（病房孩子）**——**孙承泽也答不上来**——这是真实的诚实。新一届应**主动说"病房孩子的事我们不回避，我们会陪着你"**。

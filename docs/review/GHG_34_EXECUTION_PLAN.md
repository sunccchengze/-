# GHG_3 + GHG_4 采纳执行计划｜英仔招新站双线升级

> 依据：`docs/review/GHG_3.md`（模拟指导老师审核）+ `docs/review/GHG_4.md`（模拟社长运营审核）。  
> 目标：把当前“高完成度招新展示站”升级为“内容真实、流程一致、素材合规、设备可用、可持续交接”的正式招新基础设施。  
> 原则：**代码可由 Agent 完成；事实、授权、线下流程、真实设备只能由社团确认。两条线并行，不互相等待。**

---

# 0. 总览：两条线的边界

| 线 | 负责人 | 解决的问题 | 不能替代 |
|---|---|---|---|
| A 线：网站工程与表达 | Agent | 页面、交互、文案结构、素材槽位、检查、发布清单、交接 | 不能替代真实证书、真实照片授权、真实招新通知、真机测试 |
| B 线：社团事实与运营 | 社团负责人/宣传部/社长团/指导老师 | 数据口径、照片授权、证书、链接、招新日程、真实设备测试 | 不能由 AI 主观推断或虚构 |

---

# 1. 第一阶段｜事实与流程锁定

## A-01｜建立对外事实登记册

- **负责人**：Agent
- **前置条件**：无
- **最小动作**：把网站上每一项人数、年份、届次、荣誉、人员、招新流程、活动规则列成“对外事实登记册”。
- **登记字段**：页面位置 / 当前文案 / 来源材料 / 统计截止点 / 是否需最终确认 / 负责人。
- **完成标准**：任何网站大数字都有来源，不确定项不再隐藏在文案里。
- **交付物**：`docs/PUBLIC-FACT-REGISTER.md`

## B-01｜确认事实登记册中的待确认项

- **负责人**：社长团、宣传部、项目负责人
- **前置条件**：A-01 完成
- **最小动作**：只逐条回复“确认 / 修改 / 删除”。
- **优先确认项**：
  1. 玉树届次与当年招募口径；
  2. 立邦奖项正式等级；
  3. 国家级荣誉“五项”的组成；
  4. 公众号/B站/抖音数据统计截止点；
  5. 2026 招新表、招新时间、面试通知方式；
  6. 第十六届社长团名单与职务。
- **完成标准**：网站内容中所有“待确认”变为最终口径。

## A-02｜把流程文案和真实招新表对齐

- **负责人**：Agent
- **前置条件**：B-01 中招新流程确认
- **最小动作**：核对网站“第一志愿/第二志愿/面试/录取通知/入部/旁听”与实际表单字段、通知流程一致。
- **完成标准**：新生看网站后不会期待不存在的体验、试岗、调剂或部门群。

## B-02｜招新表单最终核验

- **负责人**：社长团/招新负责人
- **最小动作**：在手机上打开正式报名表，确认：第一志愿、第二志愿、联系方式、隐私告知、提交成功页、面试通知渠道。
- **完成标准**：将“表单有效”以截图或一句确认反馈给 Agent。

# 2. 第二阶段｜真实素材与授权

## B-03｜建立素材最小包（先不追求全量）

- **负责人**：宣传部
- **最小动作**：优先从现有素材中挑出每类 1—3 张真实代表图。
- **优先级 P0**：
  1. 首页全社大合影；
  2. 第十六届社长团合影；
  3. 玉树课堂/破冰/合影；
  4. 知行秦川九峰与彬州课堂；
  5. 荣誉证书第一批；
  6. 萤火、敬老、陕博、秦岭各一张。
- **命名规则**：严格参考 `docs/ASSET-MANIFEST.md`、`docs/SUMMER-GALLERY-SLOTS.md`、`docs/QUESTIONS.md Q-022/Q-023`。
- **完成标准**：文件按路径放入本地仓库并推送。

## B-04｜图片授权与隐私标注

- **负责人**：宣传部 + 项目负责人 + 指导老师必要时确认
- **每张高风险图最小标注**：活动 / 时间 / 拍摄者 / 是否有未成年人 / 是否可公开 / 是否需要打码。
- **高风险场景**：医院、病房、患儿、特教、困境儿童、入户敬老。
- **完成标准**：不把未确认的儿童或患者正脸放入网页。

## A-03｜素材接入与视觉校正

- **负责人**：Agent
- **前置条件**：B-03/B-04 的首批素材
- **最小动作**：替换图片、检查 16:9/竖图裁切、首屏文字对比度、夏日轮播顺序、荣誉墙翻卡。
- **完成标准**：每张图在桌面和手机上都不拉伸、不遮脸、不出现破图。

## A-04｜荣誉典藏墙证据化

- **负责人**：Agent
- **前置条件**：B-03 的证书素材
- **最小动作**：将 `HONOR-01` 至 `HONOR-12` 接入对应卡片；正面金色题签，反面真实证明，补充官方来源链接位。
- **完成标准**：点击每一张荣誉卡都能翻到真实证明，不存在假证书或无法辨认的图片。

# 3. 第三阶段｜新生决策体验

## A-05｜“新生第一站”精修

- **负责人**：Agent
- **当前基础**：已上线“了解—填志愿—面试—成为干事”。
- **最小动作**：依据 B-02 的表单和通知流程，调整每一步文案；删除任何与真实流程不符的词。
- **完成标准**：新生能在 20 秒内复述招新流程。

## A-06｜部门匹配精修

- **负责人**：Agent
- **当前基础**：服务对象 + 能力方向 + 项目卡 + 旁听制度。
- **最小动作**：让“想陪伴谁”和“想练什么”在视觉上保持统一；确保推荐卡光晕、题签和排序清晰。
- **完成标准**：新生点击一次可看见推荐部门；不会误解旁听对所有部门开放。

## B-05｜部门负责人逐卡审核

- **负责人**：各部长/副社
- **最小动作**：每人只审核自己部门卡片的四件事：定位、活动、适合谁、链接。
- **完成标准**：回复“确认”或给出一句替换文案。

## A-07｜新生顾虑最终 FAQ

- **负责人**：Agent
- **前置条件**：B-02、B-05
- **最小动作**：保留最多 8—10 个真实高频问题，按“五星—流程—时间—入部—旁听—部门关系—机会—联系人”排序。
- **完成标准**：不保留假设性问题，不写综测、刷时长、未确认调剂。

# 4. 第四阶段｜社长与指导老师审核

## B-06｜指导老师审核（刘晗梦）

- **负责人**：刘晗梦老师或由社长团汇总意见
- **最小动作**：只审核以下六项：
  1. 政治与公益表达尺度；
  2. 图片授权与未成年人保护；
  3. 数据与荣誉准确性；
  4. 招新流程真实性；
  5. 小鹰是否影响正式性；
  6. 是否同意公开展示指导老师和团队信息。
- **完成标准**：形成“可上线 / 需修改”结论。

## B-07｜社长审核（王晗宇）

- **负责人**：王晗宇及社长团
- **最小动作**：审核招新表、部门容量、第一/第二志愿分配、面试排期、录取通知、旁听人数协调、社长寄语。
- **完成标准**：社长寄语替换为本人确认版本；所有招新入口有人负责。

## A-08｜按审核意见回改并冻结视觉

- **负责人**：Agent
- **前置条件**：B-06/B-07
- **最小动作**：只改审核意见涉及的事实、图、文、入口；不再新增大功能或大动效。
- **完成标准**：形成候选上线版本标签。

# 5. 第五阶段｜真实设备与上线

## B-08｜真机测试

- **负责人**：宣传部至少 2 人
- **设备矩阵**：
  - iPhone Safari / 微信；
  - Android Chrome / 微信 / QQ；
  - 375 / 390 / 430 宽度；
  - 电脑 1440 宽度。
- **最小检查项**：
  1. 首页加载与轮播；
  2. 五星动画不遮字；
  3. 小鹰拖动、收起、画画、报名跳转；
  4. 荣誉墙打开、翻卡、关闭、Esc；
  5. 暑期图片轮播；
  6. 部门推荐；
  7. QQ 群号复制；
  8. 报名表打开；
  9. 页面不横向溢出。
- **完成标准**：每项标“通过 / 设备问题 / 文案问题”，附截图。

## A-09｜真机问题修复

- **负责人**：Agent
- **前置条件**：B-08 测试结果
- **最小动作**：只处理明确复现的问题，优先级为：报名 > 内容遮挡 > 图片 > 交互 > 视觉细节。
- **完成标准**：重新构建通过，修复项有记录。

## B-09｜正式部署与发布

- **负责人**：有 Cloudflare / GitHub Pages 权限的社团成员
- **最小动作**：部署 `dist/` 完整目录；确认生产域名、二维码、表单、公众号链接。
- **完成标准**：生产 URL 可访问，静态资源完整，招新现场二维码指向正式 URL。

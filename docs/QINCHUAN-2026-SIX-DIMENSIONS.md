# 知行秦川，梦启今夏｜2026 支教成果六维度说明

> 用途：社会实践、支教成果、立邦“为爱上色”等申报材料的六维度成果填写。  
> 申报口径：整体联合呈现“知行秦川，梦启今夏”一队（彬州）与二队（九峰）成果。  
> 数据依据：用户确认 + 《2026年暑期社会实践项目实践纪实》；仅使用已确认数字。  
> 核心数据：双队17名志愿者；彬州10天、6名志愿者、服务60名以上学生、50+课时；九峰6天、11名志愿者、服务45名学生（初二20、初三25）、100+课时；合计服务105名以上学生、开展150+课程与特色活动课时。

## 正式精炼版（可直接填写）

### 1. 实践组织及筹备情况

团队由英仔爱心社统筹，组建彬州、九峰两支实践队，17名志愿者在刘晗梦老师指导下分赴两地开展支教。前期完成校方对接、往届经验交流、课程分组、物资清点、安全培训、责任书签署、急救药箱与应急预案准备；实践中实行课程、活动、调研、宣传、后勤协同分工和每日复盘机制，保障双队活动规范有序开展。

### 2. 课程设计亮点

团队坚持“五育并举、分层施教”。九峰面向初二、初三定制差异化课表，开设英语话剧与游戏、航发科普、数学艺术、化学、物理仿真、心理、非遗脸谱、配音、游园会等100+课时；彬州围绕高中生成长需求开展专业介绍、学科科普、高考心路、大学生活、美育、心理、环保、安全普法、西迁精神等50+课时。课程将大学生专业优势、地方文化与兴趣实践相结合。

### 3. 团队创新性

项目形成“双队双地、分层课程、教学调研并行”的实践模式：彬州聚焦高中生生涯启蒙与综合素养，九峰聚焦初中生学科拓展与兴趣激发；五个小组以“一组一套课程体系”协同备课、授课、复盘。团队同步开展彬州花果山窑洞民居调研、周至蔡侯纸非遗调研，将窑洞、造纸、秦腔脸谱等在地文化转化为课程与传播素材，实现支教、美育、调研相互赋能。

### 4. 实践的社会贡献

双队累计服务105名以上乡村中学生，完成150+课时课程与特色活动。团队通过专业分享、科学科普、英语表达、美育实践、心理关怀、环保与安全教育，拓展学生认知视野和表达机会；同时以实地访谈、现场观察和文化体验积累窑洞民居、蔡侯纸传承的图文资料。一位当地教师评价团队“像一座灯塔”，有学生在书信中写下“希望以后能成为像你们一样优秀的人”。

### 5. 实践的可持续性

项目依托英仔爱心社既有助学基础，形成“暑期夏令营+学期线上助学+回访沟通”的延续机制。团队成员已与部分学生保持微信联系，学期内线上助学每学期至少开展10周；十月中旬已确定回访安排。团队还将依据校方反馈、学生学情和每日复盘持续优化课程与活动设计，推动短期支教向长期陪伴延伸。

### 6. 团队传播影响力

团队由专门宣传成员全程完成照片、视频、推文和影像档案记录，已形成五分钟活动总结视频。围绕支教日常、课程亮点、非遗调研等内容发布公众号推送11篇，累计阅读1181次、获点赞106次、转发51次、推荐64次。传播以真实课堂、学生作品、调研现场和志愿者行动为重点，扩大了乡村教育、美育实践与非遗传承的关注度。

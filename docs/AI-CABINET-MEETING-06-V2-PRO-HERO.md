# AI 内阁会议六｜V2 Pro 正式首页决策

> **用户决定**：正式首页方向选择 V2，升级为 V2 Pro；其他版本暂不删除。  
> **不可变硬要求**：多图轮播、左浓右淡渐变蒙版、Logo 展示、V2 分栏结构、较原版更完整的信息密度、轮播指示器、Scroll 提示。  
> **会议目标**：在不把首页做成信息墙的前提下，完成可作为正式招新入口的 V2 Pro。

## 1. 已知证据

- 原版 Hero 的优点：轮播、Logo、招新时间、标签、Scroll 和轮播控制；缺点：居中信息层较多，视觉噪声受照片影响。
- V2 的优点：左侧阅读区 + 右侧视觉空间、明确 CTA、三项数据；缺点：静态单图、缺副标题、右侧照片缺叙事、第二 CTA 无实际跳转。
- 前几次会议结论：正式页面优先真实、可读、手机可用；CTA 只能有一个主目标；移动端不能把桌面两栏硬压缩。

## 2. 五位工程化成员讨论

### 产品/信息架构工程师

- 保留 V2 的左列叙事：徽章 → 标题 → 「英」为爱、「仔」一起 → 宗旨 → 数据 → CTA → 时间。
- 顶部不再放重复的三枚大胶囊；把权威信息压缩成一个清晰 badge，避免与三项数字竞争。
- 第二 CTA 必须真跳到 `#summer`，不再保留无行为的播放按钮。

### 视觉系统工程师

- 选择“右侧照片说明卡”，不加旋转 Logo：页面已有导航 Logo 与左侧 Hero Logo；右侧再做旋转 Logo 会抢走活动影像的真实力量。
- 遮罩采用左深右浅：桌面保证左列文字可读、右列让真实照片有呼吸；移动端改为上下深色遮罩，不强行保留左右效果。
- 数据卡不做数字弹跳等额外干扰，只做 hover/焦点状态的轻微上浮。

### 交互/可访问性工程师

- 轮播自动播放遵循 reduced-motion；提供有语义的圆点按钮和当前页 `aria-selected`。
- Scroll 提示为真实 `#about` 链接；轮播照片说明不能只靠颜色区分。
- 轮播不预加载全部大图，只使用已配置的首屏预加载与按需浏览器缓存。

### 移动端工程师

- `<lg` 时取消“左 40%/右 60%”的几何概念，改为全屏背景 + 纵向内容；保留数据三列但压缩字号和留白。
- 标题、CTA、日期在 375px 首屏可见；轮播圆点置于底部安全区，避开固定导航和 CTA。
- 不使用桌面上的绝对右侧照片说明位置；移动端将其移动到轮播控制附近。

### 性能/发布工程师

- 复用现有 `IMG_首页轮播`，不增加库或第三方脚本。
- V2 Pro 独立组件，不破坏 V1/V2/V3/V4/V5 对比；App 只把正常入口改为 V2 Pro。
- 必须通过 `npm run typecheck`、`npm run build` 后才替换正式入口。

## 3. 裁决

1. 新建 `HeroV2Pro.tsx`，不修改或删除旧 V2；
2. 正常页使用 V2 Pro，内部预览新增 `V2 Pro` 选项；
3. 使用五张轮播图及每张预设的素材槽位说明；
4. 右侧使用低干扰的照片说明卡，不使用旋转/呼吸 Logo；
5. Logo 放在左列 badge 上方，作为内容署名而不是装饰中心；
6. 数据严格为：17 届玉树支教、199 名成员、8 个项目部门；
7. 手机端按独立单栏体验实现；
8. 其余首页候选保留，等待后续确认后再清理。

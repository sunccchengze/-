# 招新文案提炼笔记（非照抄材料）

> 来源：2026 星级答辩 + 年度总结 + 活动清单  
> 原则：面向**交大新生**说人话；亮数据、讲故事、给选择；不堆公文。

## 信息架构（招新站）

1. Hero — 身份钩子 + 主 CTA  
2. About — 一句话是谁 + 两个记忆点 + 剪影  
3. Impact 数据 — 用「体感数字」不是奖状数字 alone  
4. **暑期实践 Spotlight** — 玉树 + 知行秦川主推，其余点到  
5. Why Join — 四大理由（工时/平台/成长/家）  
6. Honors — 2025–2026 新荣誉时间线  
7. Departments — 3 职能 + **8 项目**（拆启梦/拾辉、向日葵/常青藤）  
8. Social — 传播矩阵真实数据  
9. Join + FAQ + Footer

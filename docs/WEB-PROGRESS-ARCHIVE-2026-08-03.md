### 2. 新生流程

当前对外流程已按用户确认口径写入：

```text
军训扫楼了解社团
→ 公众号/网站/部门介绍
→ WPS 表单填第一、第二志愿及个人信息
→ 短信面试通知
→ 结果通知
→ 录取后学长学姐加微信
→ 以干事身份进入部门
→ 部长/副社带领参与例会和活动
```

- 新增“从了解英仔，到成为干事”模块；
- 旁听制度仅面向宣传部、常务部录取新干事；
- 开放旁听：启梦、拾辉、向日葵、常青藤；
- 旁听任务基本同等参与，正式归属不变；
- 删除“先体验再选择”“报名后立即有人联系”等错误通用化表述。

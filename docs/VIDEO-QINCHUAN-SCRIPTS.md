# Part B｜15—20 秒短片系列

## 总体发布顺序

```text
第 1 条：英语游戏（轻快、低门槛、易停留）
第 2 条：航发课（专业反差）
第 3 条：英语话剧（表达与笑声）
第 4 条：非遗脸谱/蔡侯纸（文化视觉）
第 5 条：告别会/心愿（共情收束）
第 6 条：一间教室有多少种课（总结型招新片）
```

每条间隔 1—2 天；不要同一天连发多个相似课堂片。

## 短片 01｜《我说 stand up，为什么全班都不敢动？》

### 类型

轻快反差 / 英语游戏 / 高互动。

### 时长

15—18 秒。

### 前三秒钩子

画面：学生站住不动、互相看、笑，或你说指令的瞬间。  
字幕：

```text
我说 stand up，为什么全班都不敢动？
```

### 分镜

| 时间 | 画面 | 字幕/声音 |
|---:|---|---|
| 0:00—0:02 | 学生“定住”或笑场 | 钩子字幕 |
| 0:02—0:03 | 英仔微片头 0.8—1s | 小鹰/星环/Logo |
| 0:03—0:07 | 你说 `Simon says stand up`，学生站起 | 保留真实课堂声音 |
| 0:07—0:11 | 只说 `stand up`，有人下意识动了，全班笑 | 字幕：`前面没有 Simon says！` |
| 0:11—0:15 | English Act Out：一人表演，下面同学猜 | 字幕：`开口说英语，可以先从笑出来开始。` |
| 0:15—0:18 | 学生举手/笑脸/课堂远景 | 微片尾：`知行秦川 · 梦启今夏` |

### 评论区问题

```text
你上学时最怕哪一种英语课堂游戏？
```

## 短片 02｜《航空发动机课，为什么开进了周至中学？》

### 类型

专业反差 / 知识感 / 孙承泽第一视角。

### 时长

18—20 秒。

### 前三秒钩子

画面：网页互动动画、发动机示意、学生看屏幕。  
字幕：

```text
航空发动机课，为什么开进了周至中学？
```

### 分镜

| 时间 | 画面 | 字幕/声音 |
|---:|---|---|
| 0:00—0:02 | 发动机动画 + 学生抬头 | 钩子 |
| 0:02—0:03 | 英仔微片头 | 0.8—1s |
| 0:03—0:06 | 气球松手/网页互动画面 | `从一个松手的气球开始。` |
| 0:06—0:10 | 进气、压缩、燃烧、排气动画 | `原来飞行，也能被一步步看懂。` |
| 0:10—0:14 | 学生提问/你讲课/纸面记录 | `专业知识，走出了大学教室。` |
| 0:14—0:18 | 全班/屏幕/志愿者侧影 | `知行秦川 · 把好奇带到更远的地方。` |
| 0:18—0:20 | 微片尾 | 英仔 Logo |

### 出镜口播（可选，只有一句）

```text
“这是我在周至讲的第二天，一节航发课。”
```

## 短片 03｜《花木兰和丑小鸭，为什么同时出现在一间教室？》

### 类型

话剧 / 反差 / 表达成长。

### 时长

18—20 秒。

### 前三秒钩子

```text
一间暑期教室里，为什么同时有花木兰和丑小鸭？
```

### 分镜

```text
0—2s：角色表演动作，学生笑
2—3s：英仔微片头
3—7s：分组读台词、分角色
7—12s：花木兰 / 皇帝的新装 / 龟兔赛跑 / 丑小鸭交叉一秒切
12—16s：学生上台，台下鼓掌
16—19s：字幕：
“开口说英语，不一定要从标准开始。”
19—20s：微片尾
```

### 评论区问题

```text
如果你来演，你会选哪个角色？
```

## 短片 04｜《一张脸谱，怎么把一间教室安静下来？》

### 类型

非遗视觉 / 打破节奏。

### 时长

15—18 秒。

### 前三秒钩子

直接给颜料落到面具、学生落笔、脸谱细节，不说话。

字幕：

```text
一张脸谱，怎么让一间教室突然安静？
```

### 分镜

```text
0—3s：颜料、笔尖、面具特写，保留摩擦声
3—4s：英仔微片头
4—9s：邱鑫如/张艳阳讲秦腔脸谱、学生画面
9—13s：不同学生作品连续切换
13—16s：字幕：
“有些传统，不是讲给孩子听的，是让他们亲手画出来的。”
16—18s：微片尾
```

## 短片 05｜《这六天结束前，学生写下了什么？》

### 类型

低速共情 / 告别 / 心愿。

### 时长

15—20 秒。

### 素材前提

必须有心愿便利贴、告别会、师生交流或自然告别镜头。若没有，暂不拍，不要用摆拍补。

### 分镜

```text
0—2s：手写心愿的近景
2—3s：英仔微片头
3—8s：课堂、游园、话剧、乒乓球闪回
8—13s：心愿卡/告别会/合影
13—17s：字幕：
“有些相遇，只占一个夏天，却会留很久。”
17—20s：微片尾 + 知行秦川
```

### 评论区问题

```text
你还留着学生时代写下的心愿吗？
```

# Part C｜剪辑与发布统一规范

## 字幕

- 一屏不超过两行；
- 单行尽量不超过 13 个汉字；
- 不使用密集“活动名称 + 部门 + 时间 + 口号”堆叠；
- 人声优先白字/暖白字，重点词可用暖金；
- 非遗、博物馆、安静片减少花字和转场。

## 封面

每条只保留一个问题或一句反差：

```text
我说 stand up，为什么全班都不敢动？
航空发动机课，为什么开进了周至中学？
这六天结束前，学生写下了什么？
```

不要封面再塞：校名、社团名、部门名、招新二维码、十个标签。

## 发布后 24 小时记录

| 指标 | 记录内容 |
|---|---|
| 前三秒 | 哪个画面最能留人 |
| 完播 | 15秒/20秒/45秒分别是否完成 |
| 评论 | 用户是在问活动、表达共情，还是问招新 |
| 主页 | 是否有人进入主页 |
| 转化 | 是否有人进招新群/问报名 |

## 统一置顶评论模板

```text
知行秦川，梦启今夏。这个夏天的故事还在继续。
想了解英仔爱心社，主页、公众号和招新网站见。
```

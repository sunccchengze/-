> 默认平台：抖音主发，小红书适配。  
> 素材边界：只使用已获授权的学生、志愿者、学校和调研素材；未成年人正脸按学校/家长授权情况处理。

# Part A｜五分钟正式活动总结片

## 片名建议

主标题：

```text
知行秦川，梦启今夏
```

副标题：

```text
西安交通大学英仔爱心社 2026 暑期社会实践纪实
```

## 正确定位

这不是用来冲抖音爆款的片，而是：

```text
正式、完整、可留档、可在网站播放、可投公众号/B站的活动总结片。
```

它仍然要好看，但不需要用短视频的高速刺激覆盖真实内容。

## 推荐总结构（约 5:00）

| 时间 | 章节 | 画面 | 字幕/旁白建议 |
|---:|---|---|---|
| 0:00—0:02 | 冷开场 | 学生笑、举手、话剧动作、操场跑动中任选一个最有生命力的瞬间 | 不上 Logo，不解释 |
| 0:02—0:05 | 英仔微开场 | 2—3 秒品牌微片头 | 英仔爱心社 / 知行秦川，梦启今夏 |
| 0:05—0:25 | 山海启程 | 西安出发、抵达九峰、校门、开营准备、志愿者整理课件 | “这个夏天，交大青年走进周至九峰初级中学。” |
| 0:25—0:50 | 开营相遇 | 校长、志愿者代表、学生代表、开营合影、破冰奖励 | “从陌生的名字，到一间教室里的第一声笑。” |
| 0:50—1:50 | 课堂打开世界 | 英语话剧、英语游戏、航发、数学、化学、太阳系、配音、网络辨别等按节奏快切 | 每门课只留一个最有画面感的动作，不做课程表朗读 |

| 3:25—4:05 | 并肩成长 | 午间交流、志愿者备课、拍摄、学生作品、师生自然互动 | 使用环境声/一句真实对话，减少旁白 |
| 4:05—4:35 | 告别与心愿 | 告别会、心愿便利贴、师生互诉、合影 | “短暂的相遇，会留在下一次认真学习、认真生活里。” |
| 4:35—4:52 | 回望 | 志愿者离开、校园空镜、学生背影、夕阳 | “知行秦川，梦启今夏。” |
| 4:52—5:00 | 英仔完整片尾 | 完整 5 秒片尾压缩/淡出 | Logo + 宗旨 + 官方账号/网站 |

## 旁白原则

- 不全程旁白；
- 用 5—8 句短句连接；
- 优先学生笑声、课堂答题、击鼓传花、操场环境声、纸张/画笔/掌声；
- 不使用“我们付出了很多”“孩子们被感动得落泪”等空泛或居高临下表达；
- 不把学生塑造成被动接受帮助的人，而是展示共同学习、共同创造。

## 5 分钟片的片头/片尾处理

### 开头

不要 0 秒就完整放 5 秒品牌片头。建议：

```text
0—2 秒真实钩子
2—5 秒英仔 3 秒微开场
```

这样正式片也能先抓住注意力。

### 结尾

不要在情绪最高处突然切黑底 Logo。建议：

```text
告别会/学生作品/校园空镜
→ 一句余韵字幕停 1 秒
→ 暖金线条收束
→ 英仔完整片尾
```

# Part B｜15—20 秒短片系列

## 总体发布顺序

```text
第 1 条：英语游戏（轻快、低门槛、易停留）
第 2 条：航发课（专业反差）
第 3 条：英语话剧（表达与笑声）
第 4 条：非遗脸谱/蔡侯纸（文化视觉）
第 5 条：告别会/心愿（共情收束）
第 6 条：一间教室有多少种课（总结型招新片）
```

每条间隔 1—2 天；不要同一天连发多个相似课堂片。

## 短片 01｜《我说 stand up，为什么全班都不敢动？》

### 类型

轻快反差 / 英语游戏 / 高互动。

### 时长

15—18 秒。

### 前三秒钩子

画面：学生站住不动、互相看、笑，或你说指令的瞬间。  
字幕：

```text
我说 stand up，为什么全班都不敢动？
```

### 分镜

| 时间 | 画面 | 字幕/声音 |
|---:|---|---|
| 0:00—0:02 | 学生“定住”或笑场 | 钩子字幕 |
| 0:02—0:03 | 英仔微片头 0.8—1s | 小鹰/星环/Logo |
| 0:03—0:07 | 你说 `Simon says stand up`，学生站起 | 保留真实课堂声音 |
| 0:07—0:11 | 只说 `stand up`，有人下意识动了，全班笑 | 字幕：`前面没有 Simon says！` |
| 0:11—0:15 | English Act Out：一人表演，下面同学猜 | 字幕：`开口说英语，可以先从笑出来开始。` |
| 0:15—0:18 | 学生举手/笑脸/课堂远景 | 微片尾：`知行秦川 · 梦启今夏` |

### 评论区问题

```text
你上学时最怕哪一种英语课堂游戏？
```

## 短片 04｜《一张脸谱，怎么把一间教室安静下来？》

### 类型

非遗视觉 / 打破节奏。

### 时长

15—18 秒。

### 前三秒钩子

直接给颜料落到面具、学生落笔、脸谱细节，不说话。

字幕：


### 分镜

```text
0—3s：颜料、笔尖、面具特写，保留摩擦声
3—4s：英仔微片头
4—9s：邱鑫如/张艳阳讲秦腔脸谱、学生画面

“有些传统，不是讲给孩子听的，是让他们亲手画出来的。”
16—18s：微片尾
```

## 短片 05｜《这六天结束前，学生写下了什么？》

### 类型

低速共情 / 告别 / 心愿。

### 时长

15—20 秒。

### 素材前提

必须有心愿便利贴、告别会、师生交流或自然告别镜头。若没有，暂不拍，不要用摆拍补。

### 分镜

```text
0—2s：手写心愿的近景
2—3s：英仔微片头
3—8s：课堂、游园、话剧、乒乓球闪回
8—13s：心愿卡/告别会/合影
13—17s：字幕：
“有些相遇，只占一个夏天，却会留很久。”
17—20s：微片尾 + 知行秦川
```

### 评论区问题

```text
你还留着学生时代写下的心愿吗？
```

# Part C｜剪辑与发布统一规范

## 字幕

- 一屏不超过两行；
- 单行尽量不超过 13 个汉字；
- 不使用密集“活动名称 + 部门 + 时间 + 口号”堆叠；
- 人声优先白字/暖白字，重点词可用暖金；
- 非遗、博物馆、安静片减少花字和转场。

## 封面

每条只保留一个问题或一句反差：

```text
我说 stand up，为什么全班都不敢动？
航空发动机课，为什么开进了周至中学？
这六天结束前，学生写下了什么？
```

不要封面再塞：校名、社团名、部门名、招新二维码、十个标签。

## 发布后 24 小时记录

| 指标 | 记录内容 |
|---|---|
| 前三秒 | 哪个画面最能留人 |
| 完播 | 15秒/20秒/45秒分别是否完成 |
| 评论 | 用户是在问活动、表达共情，还是问招新 |
| 主页 | 是否有人进入主页 |
| 转化 | 是否有人进招新群/问报名 |

## 统一置顶评论模板

```text
知行秦川，梦启今夏。这个夏天的故事还在继续。
想了解英仔爱心社，主页、公众号和招新网站见。
```

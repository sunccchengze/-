# 视口自测清单（请你本机点开 preview）

```bash
npm run preview
```

| 宽度 | 关注点 |
|------|--------|
| 375 | 粘性报名条、Hero 标题不溢出、部门单列、FAQ 可点 |
| 768 | 信任条三列、暑期主卡图文、导航出现 |
| 1024 | 部门 3 列、导航不换行 |
| 1440 | 容器 max 1200 居中、左右留白 |

| 视角 | 自问 |
|------|------|
| 新生 | 3 秒内知道是五星公益社吗？知道怎么报名吗？ |
| 社员 | 声音真实吗？暑期故事对得上部门吗？ |
| 老师 | 有无不当承诺/功利话术/隐私风险？ |

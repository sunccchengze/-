> 更新时间：2026-08-03

> 主素材：2026 年暑期社会实践。

> 数据口径：只使用 `docs/PUBLIC-FACT-REGISTER.md` 已确认事实。

## 一、这批视频要完成什么

不是泛泛“展示社团做过很多活动”，而是在新生进入校园、开始选社团时，让他们看完后产生三个判断：

```text
英仔做的事是真的、有场景、有长期性；
我加入后不是被要求立刻成为很厉害的人，而是会从干事开始；
我想把第一或第二志愿写给英仔。
```

### 招新转化链路

```text
短视频停留
→ 主页/置顶评论
→ 招新网站/公众号/招新群
→ WPS 报名表
→ 第一、第二志愿
→ 面试
→ 成为干事
```

### 每条短片硬标准

1. 前 3 秒看懂在拍什么；
2. 一条片只打一个爆点；
3. 真实场景优先，不摆拍、不卖惨；
4. 结尾给余韵，招新入口放主页/置顶评论承接；
5. 未成年人、病童、特殊儿童严格按授权和遮脸规则处理；
6. 不贬低其他社团，不用“唯一最强”式攻击文案。

## 二、统一英仔片头/片尾：不牺牲爆款钩子

### 核心原则

> **品牌包装服务传播，不取代传播。**

绝不在信息流开头先放 5 秒 Logo、社团名、口号。用户还没停留就会划走。

### 需要制作的两个母版

#### 1. 英仔开场母版（约 5 秒）

用途：中视频、总结片、纪录片、官网视频、B站版。

画面建议：

```text
暖金星环亮起
→ 小鹰掠过/翻页
→ 英仔 Logo
→ 「英」为爱，「仔」一起
→ 轻微翼声 + 一颗温暖的提示音
```

#### 2. 英仔结尾母版（约 5 秒）

用途：总结片、系列收束、官网视频。

画面建议：

```text
活动现场一帧停留
→ 暖金线条收束为 Logo
→ 英仔爱心社
→ 服务社会 · 奉献爱心 · 推己及人 · 薪火相传
→ 最后一帧留出招新/公众号/系列标题替换区
```

### 同时必须导出 4 个可拆版本

| 版本 | 时长 | 使用位置 |
|---|---:|---|
| Hook 后微片头 | 0.8—1.2s | 15—30 秒抖音短片，第一个钩子之后 |
| 标准片头 | 2—3s | 30—60 秒主片 |
| 完整片头 | 5s | 5分钟总结、B站、官网视频 |
| 微片尾 | 0.8—1.5s | 短片最后一句余韵之后 |
| 标准片尾 | 3—5s | 中长片、总结片 |

### 推荐剪辑结构

#### 15—20 秒反差/氛围片

```text
0.0—2.5s：真实钩子
2.5—3.3s：英仔微片头
3.3—14s：核心场景
14—18s：余韵字幕 + 微片尾
```

#### 30—60 秒主片

```text
0.0—3s：钩子
3—5s：2秒英仔片头
5—45s：叙事/反差/人物
45—55s：一句余韵 + 评论区行动指引
55—60s：标准片尾（可按节奏缩短）
```

#### 5 分钟总结片

```text
完整5秒片头
→ 正片
→ 结尾情绪收束
→ 完整5秒片尾
```

## 三、首批暑期主片矩阵

### 01｜知行秦川：梦启今夏

**定位**：招新主打 / 最适合先发布。
**核心问题**：交大学生把什么带进了乡村课堂？
**爆点素材**：开营、英语话剧、英语游戏、航发、秦腔脸谱、游园会、蔡侯纸博物馆、告别。
**主情绪**：从陌生到被叫“老师”，从一间教室到一个夏天。
**建议主片标题**：

```text
老师，你们明年还来吗？
```

**招新余韵**：

```text
有些大学生活，从一间暑期教室开始。
```

### 02｜玉树：梦绽格桑原

**定位**：社团长期主义与高原叙事。
**核心问题**：为什么十七年后，交大学生还在去同一片高原？
**爆点素材**：出发、长途路途、哈达、破冰、藏语问候、课堂、水拓漆扇、合唱。
**主情绪**：跨越山海的接力，不消费苦难。
**建议主片标题**：

```text
第十七年，我们又出发了。
```

**招新余韵**：

```text
把远方的约定，交给下一位英仔。
```

### 03｜萤火：儿童关怀

**定位**：专业、克制、尊重的陪伴。
**核心问题**：病房里的一张小桌板，可以变成什么？
**爆点素材**：画笔、剪纸、游戏材料、志愿者手部、儿童作品、培训、特教课堂。
**主情绪**：不是“拯救”，是耐心地坐在身边。
**注意**：患儿正脸遮挡，不以疾病、眼泪、脆弱经历做钩子。
**建议主片标题**：

```text
这张病房小桌，今天是一间画室。
```

### 04｜秦岭：青护秦岭

**定位**：大学生身边的行动与生态反差。
**核心问题**：捡起一个塑料瓶，后来会发生什么？
**爆点素材**：子午峪拾物夹、山路、垃圾袋、游客宣讲、自然博物馆、朱家湾访谈。
**主情绪**：环保不是口号，是看见、弯腰、解释、坚持。
**建议主片标题**：

```text
山里的一只塑料瓶，最后去了哪里？
```

### 05｜启明星：中原文脉

**定位**：文化实践与青年视角。
**核心问题**：博物馆和古城，为什么值得大学生走进去？
**爆点素材**：龙门、洛博、二里头、开封实景、采访、笔记、青年观察。
**主情绪**：不是旅游打卡，是把历史重新讲给同龄人。
**建议主片标题**：

```text
我们去洛阳和开封，不只是为了拍照。
```

## 五、孙承泽的主理人位置

> **不是“最强剪辑师”的炫技人设，而是“把英仔真实行动剪成别人愿意留下来看的故事的人”。**

可反复使用的出镜方式：

1. 片头一句真话：`这节航发课，是我在周至讲的第二天。`
2. 镜头后日记：`剪到这一段时，我才知道六天过得这么快。`
3. 剪辑拆解：`为什么这条公益视频的前两秒不能先放 Logo？`
4. 专业视角：`航空发动机课为什么会出现在周至中学？`

## 六、首周执行顺序

### Day 1

- 压缩知行秦川 5 分钟总结视频，上传网站；
- 选出知行主片所需 20—40 个核心镜头；
- 确定一句真实钩子和一条余韵字幕。

### Day 2

- 剪出知行主片 45 秒版本；
- 同步剪出 15 秒安静氛围测试版；
- 从片中拆出 1 条“镜头后英仔”宣传部衍生内容。

### Day 3

- 发布知行主片；
- 置顶评论只承接：官网 / 公众号 / 招新群；
- 记录前三秒、完播、评论关键词、主页访问和招新咨询。

### Day 4—7

- 复盘知行数据；
- 制作玉树主片；
- 制作秦岭或启明星反差片；
- 完成英仔片头/片尾母版及四个可拆版本。

## 七、统一检查清单

- [ ] 前 3 秒没有 Logo、长片头或解释性废话；
- [ ] 每条只有一个情绪/知识/反差核心；
- [ ] 片头/片尾按时长拆用，不占用钩子；
- [ ] 封面文字与标题不重复堆砌；
- [ ] 评论区有一个自然的问题或入口；
- [ ] BGM 使用平台曲库/授权来源；
- [ ] 未成年人、病童、特殊儿童影像符合授权遮脸规则；
- [ ] 真实数据与 `PUBLIC-FACT-REGISTER` 一致；
- [ ] 发布后 24 小时记录数据和评论，不只看播放量。

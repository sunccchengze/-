## 一、把模糊意图变成可执行规格

大多数"AI 没发挥好"不是模型不行，是你给的指令有歧义。高质量指令 = **目标 + 上下文 + 约束 + 验收标准**。

| 要素 | 作用 | 示例 |
| --- | --- | --- |
| 目标 | 告诉它要达成什么 | 写小红书种草文案 |
| 上下文 | 告诉它为谁、在什么场景写 | 25–35 岁女性、单价 ¥299 的便携咖啡机 |
| 约束 | 限制形式与语气 | 3 个版本、每篇 ≤150 字、语气轻松带 emoji |
| 验收标准 | 什么算合格 | 必须强调"通勤也能喝现磨"、结尾有互动钩子 |

**❌ 反例：**

> "帮我写个好点的营销文案"

**✅ 正例：**

> "给一款面向 25–35 岁女性、单价 ¥299 的便携咖啡机写小红书文案，3 个版本，每篇 ≤150 字，语气轻松带 emoji，强调'通勤也能喝现磨'，结尾必须有互动钩子"

**核心技巧**：给一个示例（few-shot）比写一大段要求更管用。说"风格参考这个"然后贴一段，Agent 立刻就懂了。

## 二、把"一次性问答"升级成"工作流"

Agent 最强的地方不是单次输出，而是**多步闭环**：

1. **先对齐再动手**：复杂任务先让 Agent 复述理解和拆解步骤，你确认后再执行，避免跑偏。
2. **分块 + 迭代**：大任务拆成小步，每步看结果、提反馈（"第二点太啰嗦，收紧"），比一次要完美结果可靠得多。
3. **让它自查**：明确说"完成后用 critic 视角挑出 3 个最弱的地方并改进"，质量会明显提升。

## 三、用透你手上的工具杠杆

你这个 Agent 不只是聊天框，它能**真干活**：

- **工作区文件**：让它把长文档、代码、数据写进文件，跨越上下文保存，下次接着用——等于给它"长期记忆"。
- **联网搜索 / 抓网页**：让它先查最新事实再回答，别让它凭记忆编造（尤其涉及 2024 年后的信息、价格、法规）。
- **跑代码**：数据分析、批量处理、验证计算，直接让它写脚本执行，比手算或纯描述准。
- **生成图 / 语音**：需要配图或配音的产出物直接产出，不用你再去找素材。

**诀窍**：遇到"它答错了"，往往是工具没用上。比如问"这个数对不对"时，让它写代码算一遍，而不是凭感觉。

## 四、角色设定与质量契约

开头给它一个清晰身份和评判标准，全程生效：

> "你是我专属的高级战略顾问，所有输出默认做到：论点有依据、给出可执行的下一步、主动指出风险和盲点。不确定时明确说不确定，不要编造。"

再配一句**"如果我的要求有歧义或信息不足，先问清楚再动手"**——这正是我会被允许反问你的机制，能省掉大量返工。

---

## 五、建立你的"Agent 协作习惯"

- **喂背景文档**：把项目背景、品牌调性、常用模板存成文件，让它每次先读——一致性拉满。
- **沉淀复用资产**：好的提示词、输出模板让它存成文件，以后"按上次那个框架再来一份"。
- **验收前置**：先定义"什么算成功"，再让它做，而不是做完你才发现方向不对。

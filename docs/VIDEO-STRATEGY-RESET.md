## 1. 为什么英仔具备做出爆款的条件

英仔不缺活动，缺的是把活动剪成“用户愿意停下来看的故事”的选择与结构。

英仔的稀缺资产有四类：

1. **长期性**：玉树第十七届、知行秦川、大手拉小手、敬老、文博等不是一次性摆拍；
2. **场景反差**：交大学生在乡村课堂、护理院、病房、博物馆、秦岭之间切换；
3. **专业能力**：航发科普、英语话剧、陕博讲解、摄影剪辑、活动组织；
4. **活人关系**：新生从干事开始、部长带队、旁听跨部门、全社活动和全校玉树招募。

但这些不能同时塞进一条视频。每条视频只选择一个爆点：

```text
一个场景
→ 一个情绪/反差/知识点
→ 一个能引发评论的问题
→ 一句余韵式 CTA
```

## 2. 内容三层架构

### A 层：破圈主片（每月 2—4 条）

目标：涨粉、建立英仔人格、让外校用户也愿意转发。

形式：20—60 秒，强开场、真实情绪、电影化 B-roll、少口播。

素材优先：知行秦川、玉树、青春伴夕阳、陕博。

### B 层：新生决策片（招新期每周 1—2 条）

目标：让交大新生知道“加入后是什么样”。

形式：15—35 秒，学生第一视角、信息清楚、软 CTA。

素材优先：部门的一天、旁听、第一次破冰、宣传部镜头、部长带活动。

### C 层：部门可持续栏目（每周 1—3 条，按素材）

目标：让每个部门有可复用内容，而不是只等大活动。

形式：8—20 秒，单一场景、低制作成本、高频记录。

## 4. 首批五条主片（默认方案）

### 01｜共情片：知行秦川

**暂定标题**：`“老师，你明年还来吗？”`  
**类型**：共情 / 真实关系  
**时长**：35—45 秒  
**前三秒**：学生与志愿者告别的真实瞬间或一句问题。  
**结构**：开营陌生 → 英语话剧/游戏/航发/脸谱/游园 → 告别/心愿。  
**评论问题**：`你还记得第一次被叫“老师”是什么时候吗？`  
**CTA**：片内只留“知行秦川，梦启今夏”；招新信息放置顶评论。

### 02｜差异片：英仔不是一次活动

**暂定标题**：`“一个社团，为什么会有11个部门？”`  
**类型**：信息反差 / 招新  
**时长**：25—35 秒  
**前三秒**：玉树高原、陕博展厅、护理院、校园回收四连切。  
**结构**：不同场景 → 不同人群 → 干事/部长/副社 → 真实招新流程。  
**CTA**：`先认识英仔，把心动写进志愿。`

### 03｜打破节奏片：15秒安静陪伴

**暂定标题**：`“别划走，听完这15秒。”`  
**类型**：快中慢 / 氛围  
**时长**：15—18 秒  
**素材**：空教室、孩子写字、老人手部、博物馆脚步、秦岭风声。  
**声音**：环境声 + 极轻音乐，不口播。  
**字幕**：`有些大学生活，不只发生在教室里。`

### 04｜能力反差片：交大学生把专业带到课堂

**暂定标题**：`“航空发动机课，为什么出现在周至中学？”`  
**类型**：知识反差 / 人物  
**时长**：25—40 秒  
**人物视角**：孙承泽。  
**素材**：御风记网页互动、学生抬头、纸面/投影、英语游戏与话剧交叉。  
**核心**：专业不是只留在课表里，也可以成为孩子认识世界的一扇窗。  
**CTA**：`前卫部 · 知行秦川。`

### 05｜招新决策片：第一次加入英仔

**暂定标题**：`“选社团前，先看完这30秒。”`  
**类型**：新生信息 / 转化  
**时长**：30—40 秒  
**结构**：扫楼宣传单 → 公众号/网站 → 第一/第二志愿 → 面试 → 成为干事 → 部长带活动 → 旁听/全社机会。  
**避免**：不要用“先体验再选部”。  
**CTA**：`2026 招新，第一、第二志愿等你写下。`

## 5. 孙承泽作为视频主理人的定位

不是把你包装成“全社最强剪辑师”的炫技标签，而是：

> **用交大学生的镜头，把公益活动里真正值得留下的瞬间讲出来的人。**

你可稳定出镜的三种方式：

1. **片头一句真话**：例如“这节航空发动机课，是我在周至讲的第二天。”
2. **镜头后日记**：例如“剪到这一段时，我才知道这六天过得这么快。”
3. **专业拆解**：例如“这条视频的开头为什么不用社团 Logo？”

这会让官方账号保留组织可靠性，同时拥有学生创作者的活人感。

## 6. 制作规格

### 统一画面

- 抖音主版本：9:16；
- 小红书适配：9:16，强化封面和首屏文字；
- B站/官网：16:9 纪录版；
- 网站视频播放器：16:9，5 分钟总结片可直接嵌入；
- 色调：沿用网站的暖金、莫兰迪红、低饱和自然光；
- 片尾：不超过 1.5 秒，英仔 Logo + 一句余韵，不做长片尾。

### 音乐与合规

- 优先平台曲库或已获得授权音乐；
- 真实人声、环境声优先于泛滥煽情 BGM；
- 有 AI 重绘、AI 配音、AI 生成场景时按平台规则进行标注；
- 未成年人、病童、特殊儿童遵守网页同等甚至更严格的授权/遮脸规则。
